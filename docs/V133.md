# What v133 is

v133 is the best real run with cutters and slitters in the project, on the plan-12oct dataset.

| | |
|---|---|
| **Plan** | plan-12oct (PCR 13 / TBR 14), window 12-Oct 07:00 → 22-Oct 07:00 |
| **Opening WIP** | `CTP_Opening_WIP` 12-Oct 06:31, plus the 17:26 correction |
| **Masters** | the 14-Oct database pull |
| **Result** | **132,919 / 175,628 cured (75.7 %)**: PCR 104,672, TBR 28,247. Built PCR 101,824, TBR 29,110. 112 green tyres scrapped |

## Key settings (`engine/config.yaml`)

| Setting | v133 value | Meaning |
|---|---|---|
| `masters_unlimited` | on | master compounds are not a limit (mixing capacity goes to finals) |
| `final_on_master_mixers` | `*` → K270M, K430-1, K430-2, F440 | finals may also run on the master mixers |
| `mix_planner` | cover / gap 15 h, 4RC priority 8 h, 120 s clean-out after every final, **butyl gap wait 6 h** | mixing planned first (fixed lots) |
| `outsourced_items` | CWCH30256, CWBHI34, TBA827, TCA313, MS43, MS70, MB100 | bought in, not made |
| `master_fixes` | SP003 old kg per tyre; belt cutter 15 cuts / min | fixes on the 14-Oct masters |
| `linespeed_file` | `faster_of_routing` | speed = the faster of database routing and the plant line-speed file (inner liner, chafer slitters, TBR body ply and belt edge filler stay on routing) |
| `capstrip_direct` | CAP 66 - CAPSTRIP → CAP 66-MOTHERROLL | cap strip taken from the mother roll; 701 / 702 not scheduled |
| `edgegum_direct` | EGSL01 / 02 / 03, BPGSL01 → EG01 / 02 / 03, BPG01 | belts / plies take edge gum directly; 601 cap-ply cutter step not scheduled |
| `fourrc_rules.item_campaign` | MONOCHAFER 48 h, whole dip | MONOCHAFER made about every 2 days, like the plant |
| `fourrc_rules.urgent_pull` | MONOCHAFER, late vs need, keep one go | a MONOCHAFER run that would be late moves into an idle 901 gap (**the v133 change**) |
| `ctb_wip_assumptions` | expired 0 h, flow 24 h | the plan generator's WIP assumptions |
| `kit_gate_assume_first_h` | 24 h; cap strip, mother roll, edge gum | assumed present for the first 24 h of building |
| `efficiency_override` | 1.0 | machine efficiency taken as 1 |
| `gt_transfer_time_min` | 120 | green tyre 2 h before curing |
| `building_plan_echo` | on | component demand from the building plan |

## How v133 was reached

Each step was kept by the user.

| Version | Change |
|---|---|
| v87 | WIP correction (12-Oct 17:26), masters unlimited, batch sizes from routing |
| v98 | bought-in items, finals on master mixers, 120 s clean-out, 901 lot pool / wire load / FEFO / left-shift settings |
| v117 | 14-Oct masters, `master_fixes`, cap strip / edge gum 24 h, MONOCHAFER 2-day campaign |
| v120 / v122 | cap strip direct, edge gum direct, long-item mixing cover (B186, 30G) |
| v124 | butyl block waits up to 6 h for the repeat gap |
| v130 | line speed = faster of database routing and the plant file |
| **v133** | MONOCHAFER on time (urgent pull into idle 901 gaps) |

Full history: `latest_schedule/RUN_LOG.md` and `BUSINESS_RULES_LOG.md` in the main project.
